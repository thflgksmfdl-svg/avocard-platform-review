# AVOCARD Shopify theme

A mirror of the live Shopify theme that runs `avocard.co.kr` ("Avocard Preview 2026-08-07", theme id `158012932267`). It is edited directly in Shopify's own code editor and deployed there — this copy is kept here for version history and review, not pulled or pushed automatically.

## Scope

Only the deployable theme folders are included: `assets/`, `config/`, `layout/`, `locales/`, `sections/`, `snippets/`, `templates/`. Internal planning docs, notes and design drafts that live alongside the theme in the working copy are intentionally left out, consistent with how this repo already excludes `docs/` for `backend/` and `admin/`.

## Keeping this in sync

There's no CI pipeline wired up yet. After a change is made live in the Shopify code editor, copy the same folders over this directory and commit.
